EXCORDERは、iPhoneに搭載された複数のセンサー情報をリアルタイムに可視化するiPhone センサー アプリです。カメラ映像、対応機種でのLiDAR距離、磁場、GPS位置、気圧、動き、マイク音声を、ひとつのインターフェースで探索できます。

02 / CAPABILITIES

EXCORDERでできること

アプリに実装された機能をもとにした、リアルタイムツールです。

IMG.01

画像・距離

背面カメラ映像に方位・垂直角を表示し、RGB由来の疑似スペクトラムも確認できます。対応するLiDAR搭載機種では、画面中央までの概算距離も表示します。

NAV.02

位置・環境

現在地、座標、方位、GPS高度、気圧、相対高度、周辺の気象情報を表示します。

MAG.03

磁場

3軸の磁場、合成磁場強度、ベクトル方位・仰角を取得し、3D投影で可視化します。磁場の強さを表す単位はµT（マイクロテスラ）で、1 µTは100万分の1テスラです。

MOT.04

モーション・振動

100 Hzの3軸加速度を追跡し、0〜50 Hzの振動スペクトラム、ピーク周波数、振幅を確認できます。

AUD.05

音響解析

マイク入力の相対レベル（dBFS）と40 Hz〜16 kHz・32帯域のスペクトラムを、デジタルブースト付きで表示します。

VOC.06

音声デコード

日本語、英語、スペイン語、韓国語、ドイツ語、フランス語をライブ文字起こし。対応するiOSでは翻訳も利用できます。

※ 利用可否や精度は、iPhoneの機種、iOSバージョン、権限、環境、センサー対応状況により異なります。EXCORDERは観察・参考用途であり、安全上重要な判断や校正済みの専門計測には使用できません。

03 / SENSORS

EXCORDERで使えるiPhoneのセンサーと表示内容

SENSOR / 01

カメラ・LiDAR

背面カメラのライブ映像に方位と端末の垂直角を重ねて表示します。LiDAR搭載の対応iPhoneでは、画面中央までの概算距離も表示できます。カメラの色スペクトラムはRGB値から生成した疑似表示で、分光器による実測ではありません。

SENSOR / 02

磁気センサー・コンパス

iPhoneの磁気センサーから得られる3軸の磁場、合成強度（µT）、ベクトル方向を数値と3D投影で確認できます。コンパスの方位はカメラ画面とナビゲーション画面にも表示されます。

SENSOR / 03

GPS・気圧計

地図上の現在地、緯度・経度、GPS高度を確認できます。気圧計は気圧と相対高度の変化を表示します。周辺の気温・湿度はOpen-Meteoの気象情報であり、iPhone内蔵の温度・湿度センサーによる実測ではありません。

SENSOR / 04

加速度センサー・端末の姿勢

100 Hzで取得する3軸加速度と、0〜50 Hzの振動スペクトラム、ピーク周波数・振幅を確認できます。垂直角や磁場ベクトルの表示には、ジャイロスコープなどのモーションセンサー情報を統合するCore Motionの端末姿勢情報を利用します。

SENSOR / 05

マイク

マイク入力の相対レベル（dBFS）と40 Hz〜16 kHzの音響スペクトラムを表示します。デジタルブーストを調整して小さな信号を確認できます。表示はデジタル音声の相対レベルであり、校正済みの音圧測定ではありません。

04 / HARDWARE

iPhoneに、すでにあるセンサーを活用。

追加ハードウェアは必要ありません。

iPhoneには、カメラ、モーションセンサー、マイク、位置情報機能などが搭載されています。EXCORDERは対応する値をひとつにまとめ、端末が検知している情報をリアルタイムに見せます。

LiDAR、気圧データ、音声処理、翻訳など、一部機能の利用可否は端末とiOSバージョンによって異なります。

05 / CONCEPT

サイエンスと、SFが出会う。

EXCORDERは、実際のセンサーデータと、SFが想像させてくれた未来の計測器に着想を得た独自インターフェースを組み合わせます。かつて遠い未来に感じられた体験が、いま手のひらにあります。

06 / HISTORY

1973 — Day 0

EXCORDERの始まりは、2026年ではありません。

1973年頃、北海道。

私はまだ9歳くらいの子供でした。

ある日、偶然テレビで『宇宙大作戦 (Star Trek)』を見ました。

私が覚えている最初の場面は、カークとスポックが3次元チェスをしているところです。

そして、スポックが人間について語り、少し笑う。

その姿を見た私は、スポックに強烈に憧れました。

科学。
論理。
コンピュータ。

未知のものを測定し、得られたデータから答えを導き出すこと。

「こんなことをやってみたい」

子供だった私がそう思ったことが、その後、コンピュータの世界へ進む最初のきっかけになりました。

それから約半世紀。

コンピュータ、電子回路、センサー、通信。

私はずっと、あの日に憧れた世界の延長線上で物を作ってきました。

そして2026年。

iPhoneの中にあるカメラ、LiDAR、磁気センサー、加速度センサー、GPS、気圧計、マイクなどを見て、子供の頃に憧れた「あの未来の計測器」を、自分の手で作ってみようと思いました。

それが、EXCORDERです。

EXCORDERは、市場調査から生まれたアプリではありません。

流行を追って作ったものでもありません。

1973年頃、北海道でテレビを見ていた一人の少年の憧れが、約半世紀かけて形になったものです。
